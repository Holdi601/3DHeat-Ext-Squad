# Претварање демоа {#converting-demos}

```text
heat3d-squad-demo <demos or folders> -o <folder> [--flat] [--json]
python -m heat3d_ext_squad ...          исто, без инсталације
```

## Корак по корак {#step-by-step}

Први пут у командној линији? Прво прочитајте [Пре почетка](before-you-start.md).

1. Инсталирајте једном: `git clone https://github.com/Holdi601/3DHeat-Ext-Squad`,
   отворите терминал у тој фасцикли, покрените `python -m pip install -e .`
   (Python 3.10 или новији; доноси pyarrow и numpy).
2. Ставите `.replay` датотеке у једну фасциклу, или их наведите једну по једну.
3. Покрените `heat3d-squad-demo <folder> -o out`.
4. Требало би да видите по један ред за сваки демо: његов слој, играче и редове,
   и где је табела завршила. Сваки демо постаје четири засебне датотеке у `out/<map>/`
   (не `.3dheat` контејнер); учитајте `.parquet` у 3DHeat приказивач.

![Покретање над демоом који тестови праве](../assets/img/run.svg)

Слика приказује покретање над демоом који прави тест (`tests/test_stream.py`),
а не над правим мечем.

## Опције {#options}

| Опција | Подразумевано | Шта ради |
|---|---|---|
| `demos` (једна или више) | - | `.replay` датотеке, или фасцикле које их садрже |
| `-o`, `--out` | обавезно | фасцикла у коју се пише; сваки демо иде у `<out>/<map>/` |
| `--flat` | искључено | пише право у фасциклу, без фасцикле `<map>/` |
| `--json` | искључено | исписује по један ред JSON-а за сваки демо на стандардни излаз (за програме које позивају команду): `demo`, `ok`, `parquet`, `match`, `sidecars`, `lost`, `rows`, `players`, `layer`, `recorded_unix`; демо који није успео исписује `demo`, `ok: false` и `error` уместо тога |
| `--version` | - | исписује верзију и стаје |

Свака опција, онако како је програм исписује: [Референца команди](../cli-reference.md).

Фасцикла мапе је име мапе узето из путање нивоа коју демо наводи
(`/Game/Maps/<Map>/Gameplay_Layers/<Layer>` даје `<Map>`).

Излазни статус: 0 када су сви демои претворени; 1 када је неки није успео
(остали се ипак пишу) или када није нађена ниједна `.replay` датотека.

## Шта излази {#what-comes-out}

| Датотека | Шта садржи |
|---|---|
| `<demo>.parquet` | табела: позиције и догађаји, по један ред сваки ([Табела](output-table.md)) |
| `<demo>.match.json` | документ о мечу ([Документ о мечу](output-match.md)) |
| `<demo>.entities.parquet` | пратећа датотека: свака промена својства и сваки удаљени позив, цео |
| `<demo>.packets.parquet` | пратећа датотека: делови датотеке и све што није прочитано, цело |

Табела и документ о мечу су исти пар који пише 3DHeat CS2 алат.
Приказивач отвара табелу директно и изоставља пратеће датотеке кад се учита
цела фасцикла.

## Примери {#examples}

```bash
heat3d-squad-demo D:\SquadDemos -o out                 # сваки демо у фасцикли
heat3d-squad-demo one.replay two.replay -o out --flat  # право у out/
heat3d-squad-demo D:\SquadDemos -o out --json          # по један JSON ред за сваки демо
```

`D:\SquadDemos` је пример фасцикле на диску D: користите своју.
