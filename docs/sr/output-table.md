# Табела: `<demo>.parquet` {#the-table-parquet}

Један ред по узорку или догађају. Узорак се узима кад год сервер пренесе
кретање актера, до 8 пута у секунди (брзина снимања демоа)
док се креће.

![Први редови табеле једног пробног демоа](../assets/img/table.svg)

## Колоне {#columns}

| Колона | Шта је |
|---|---|
| `time` | секунди од почетка снимања |
| `x`, `y`, `z` | позиција у Unreal јединицама (центиметри), Z навише |
| `dirX`, `dirY`, `dirZ` | куда војник гледа: скретање тела и нагиб погледа, као јединични вектор (код возила: водоравно) |
| `yaw`, `pitch` | исто у степенима; `pitch` је нагиб навише од хоризонта, само за војнике |
| `health` | здравље војника, бота или возила у том тренутку, онда кад га је сервер послао (здравље војника пада испод 0 док је рањен) |
| `speed` | пренесена брзина, cm/s |
| `player` | име играча; `bot <id>` за бота; за возило или постављив предмет који нико не поседује, његова класа; за хитац из оружја возила, играч који седи у том возилу |
| `team`, `faction` | број тима у Squad-у (1, 2) и његова постава фракције, **у том тренутку**: играчи могу да промене страну |
| `squad` | број одреда, -1 кад није ни у једном |
| `event` | шта ред представља (испод) |
| `pawn` | план војника (`SQSquidBot` за бота), возило, или за `fire` оружје |
| `seat` | за митраљеско или путничко место, сопствени пијун тог места |
| `detail` | за `fire` позив оружја који је поставио хитац, за `hit` врста штете, за `removed` зашто је канал затворен (`Destroyed`, `Dormancy`...) |
| `entity` | актер о којем ред говори (његов net GUID): `entity` редова у пратећим датотекама |
| `match` | име демоа |

## Догађаји {#events}

| `event` | Ред за | Шта |
|---|---|---|
| `position` | војник или бот пешице | узорак кретања |
| `vehicle` | војник у копненом возилу или хеликоптеру | узорак на позицији возила |
| `wounded`, `revived`, `death` | војници и ботови | где се догодило |
| `spawn`, `damaged`, `destroyed`, `removed` | возила, постављиви предмети, утврђења, сандуци, хеликоптери | где су били |
| `seat` | играч | заузео место |
| `fire` | стрелац | хитац: одакле је изашао, његов смер као `yaw`/`pitch`/`dirX..Z` |
| `hit` | возило | погодак по возилу: где |

Како се догађаји читају, види се у [Како се демо чита](how-it-works.md#how-the-events-are-read).

## У приказивачу {#in-the-viewer}

Подножје Parquet датотеке носи упутства за читање под кључем `heat3d`: Z навише,
ниједна оса није пресликана, размера 1, па приказивачу није потребно
мапирање колона. Учитајте табелу на картици Топлотна мапа; види
[Унос података](https://holdi601.github.io/3DHeat/getting-data-in.html)
и [Мапирање колона](https://holdi601.github.io/3DHeat/column-mapping.html)
у документацији приказивача.
