# Одржавање ове документације {#maintaining-these-docs}

Контролна листа за свако издање, да странице никад не заостану за кодом.

1. **Поново генеришите референцу.** `python tools/gen_docs_reference.py` поново пише
   [Референца команди](../cli-reference.md) из самог `--help` програма и колона излаза.
   `python tools/gen_docs_reference.py --check` излази са 1 кад је објављена страница
   застарела.
2. **Наведите шта се променило.** `git log v<VERSION>..HEAD --oneline`, где је
   `<VERSION>` последња објављена верзија (датотека `VERSION` при издавању). Свака
   нова функција, опција и колона излаза треба да добије место на некој страници и
   ред у одељку **Docs** у [`CHANGELOG.md`](https://github.com/Holdi601/3DHeat-Ext-Squad/blob/main/CHANGELOG.md).
3. **Независан преглед.** Неко ко није писао странице чита README и сваку
   промењену страницу, укључујући слике, три пута: као почетник који никад није
   користио терминал, као осмогодишњак, и као стручњак који проверава сваку
   опцију према `--help`. Примери користе само измишљена имена и бројеве.
4. **Поправите** све што преглед нађе.
5. **Преводи.** Свака преведена страница бележи хеш енглеске странице из које је
   настала. Поново преведите странице чији се енглески извор променио, па прегледајте
   сваки језик: јасан текст, исправне ознаке на дијаграмима, иста реч као у
   преведеном интерфејсу приказивача 3DHeat-а.
6. **Покрените тестове** (`pytest`).
7. **Објавите** тек након одобрења власника.

## Преводи: команде {#translations-the-commands}

Сајт је преведен на 40 језика 3DHeat приказивача: енглески је у `docs/`, сваки други
језик у `docs/<lang>/` са истим именима датотека. `tools/docs_i18n.py` води евиденцију:

```bash
python tools/docs_i18n.py hashes             # после сваке енглеске измене: забележите хеш сваке странице
python tools/docs_i18n.py svg-strings        # после сваке измене слике: ознаке за превод
python tools/docs_i18n.py status             # по језику: тачне, застареле, недостајуће странице
python tools/docs_i18n.py todo --lang de     # немачке странице за (поновни) превод
python tools/docs_i18n.py svg-build --lang de    # немачке слике из docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # означи немачке странице хешом енглеске
python tools/docs_i18n.py check              # излази са 1 кад су хешеви или ознаке застарели
```

Преводи само оно што `todo` наводи: задржите Markdown, везе, код и имена датотека и
колона као што јесу, преведите наслове и описе слика, и користите речи самог приказивача
3DHeat-а за његова дугмад и панеле (`src/i18n/locales/<lang>/`). Генерисане странице
са референцама и слике терминала остају на енглеском. На сајту, застарео превод то
каже и води на енглеску страницу; недостајућа страница пада на енглеску. Мени за
језик у заглављу и преусмеравање по језику прегледача на почетној страници долазе из
`docs/_includes/`.
