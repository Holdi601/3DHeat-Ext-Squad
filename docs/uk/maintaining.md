# Підтримка цих документів {#maintaining-these-docs}

Контрольний список для кожного випуску, щоб сторінки ніколи не відставали від коду.

1. **Перегенеруйте довідку.** `python tools/gen_docs_reference.py` перезаписує
   [Довідку з команд](../cli-reference.md) з власного `--help` програми і колонок
   виводу. `python tools/gen_docs_reference.py --check` завершується з кодом 1,
   коли закомічена сторінка застаріла.
2. **Складіть список змін.** `git log v<VERSION>..HEAD --oneline`, де `<VERSION>` -
   остання випущена версія (файл `VERSION` на момент випуску). Кожна нова функція,
   параметр і колонка виводу повинні мати місце на сторінці і рядок у розділі
   **Docs** файлу [`CHANGELOG.md`](https://github.com/Holdi601/3DHeat-Ext-Squad/blob/main/CHANGELOG.md).
3. **Незалежний перегляд.** Хтось, хто не писав сторінки, читає README і кожну
   змінену сторінку, включно з малюнками, тричі: як початківець, який ніколи не
   користувався терміналом; як восьмирічна дитина; і як експерт, який перевіряє
   кожен параметр за `--help`. Приклади використовують лише вигадані імена та числа.
4. **Виправте** все, що знайде перегляд.
5. **Переклади.** Кожна перекладена сторінка записує хеш англійської сторінки, з якої
   її зроблено. Перекладіть заново сторінки, чиє англійське джерело змінилося, потім
   перевірте кожну мову: зрозумілий текст, правильні написи на діаграмах, ті самі
   слова, що в перекладеному інтерфейсі самого переглядача 3DHeat.
6. **Запустіть тести** (`pytest`).
7. **Надсилайте на сервер** лише після дозволу власника.

## Переклади: команди {#translations-the-commands}

Сайт перекладено на 40 мов переглядача 3DHeat: англійська в `docs/`, кожна інша мова в
`docs/<lang>/` з тими самими іменами файлів. `tools/docs_i18n.py` веде облік:

```bash
python tools/docs_i18n.py hashes             # після будь-якої англійської зміни: записати хеш кожної сторінки
python tools/docs_i18n.py svg-strings        # після будь-якої зміни малюнка: написи для перекладу
python tools/docs_i18n.py status             # за мовами: актуальні, застарілі, відсутні сторінки
python tools/docs_i18n.py todo --lang de     # німецькі сторінки для (повторного) перекладу
python tools/docs_i18n.py svg-build --lang de    # німецькі малюнки з docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # позначити німецькі сторінки англійським хешем
python tools/docs_i18n.py check              # код 1, коли хеші або написи застарілі
```

Перекладайте лише те, що показує `todo`: залишайте Markdown, посилання, код, назви
файлів і колонок без змін, перекладайте заголовки та описи малюнків, а для кнопок і
панелей переглядача 3DHeat використовуйте його власні слова (його
`src/i18n/locales/<lang>/`). Згенеровані сторінки довідки і малюнки терміналу
лишаються англійськими. На сайті застарілий переклад це повідомляє і посилається
на англійську сторінку; відсутній переклад переходить на англійську. Мовне меню в
заголовку і перенаправлення на головній сторінці за мовою браузера беруться з
`docs/_includes/`.
