# Таблиця: `<demo>.parquet` {#the-table-parquet}

Один рядок на кожен зразок або подію. Зразок береться щоразу, коли сервер
реплікував рух актора, до 8 разів на секунду (частота запису демо), поки актор рухається.

![Перші рядки таблиці синтетичного демо](../assets/img/table.svg)

## Колонки {#columns}

| Колонка | Що це |
|---|---|
| `time` | секунди від початку запису |
| `x`, `y`, `z` | положення в одиницях Unreal (сантиметрах), Z вгору |
| `dirX`, `dirY`, `dirZ` | куди дивиться солдат: курс тіла і кут нахилу погляду як одиничний вектор (для техніки: горизонтально) |
| `yaw`, `pitch` | те саме в градусах; `pitch` — вгору від горизонту, лише для солдатів |
| `health` | здоров'я солдата, бота або техніки в той момент, коли сервер його надіслав (здоров'я солдата падає нижче 0, коли він поранений) |
| `speed` | реплікована швидкість, см/с |
| `player` | ім'я гравця; `bot <id>` для бота; для техніки або розгортання, яке ніхто не контролює, — її клас; для пострілу з зброї техніки — гравець, який сидить на цій техніці |
| `team`, `faction` | номер команди Squad (1, 2) і її фракція **на той момент**: гравці можуть змінювати сторону |
| `squad` | номер загону, -1, якщо не в загоні |
| `event` | що означає рядок (нижче) |
| `pawn` | блюпринт солдата (`SQSquidBot` для бота), техніка, а для `fire` — зброя |
| `seat` | для місця турелі або пасажира — сама піхотна одиниця цього місця |
| `detail` | для `fire` — виклик зброї, що розмістив постріл; для `hit` — тип пошкодження; для `removed` — причина закриття каналу (`Destroyed`, `Dormancy`...) |
| `entity` | актор, про якого рядок (його net GUID): `entity` рядків супутніх файлів |
| `match` | назва демо |

## Події {#events}

| `event` | У рядку | Що це |
|---|---|---|
| `position` | солдат або бот пішки | зразок руху |
| `vehicle` | солдат у наземній техніці або гелікоптері | зразок у положенні техніки |
| `wounded`, `revived`, `death` | солдати і боти | де це сталося |
| `spawn`, `damaged`, `destroyed`, `removed` | техніка, розгортання, укриття, ящики, гелікоптери | де вони були |
| `seat` | гравець | зайняв місце |
| `fire` | стрілець | постріл: звідки вилетів, його напрям як `yaw`/`pitch`/`dirX..Z` |
| `hit` | техніка | влучання в техніку: де |

Як читаються події, описано в [Як читається демо](how-it-works.md#how-the-events-are-read).

## У переглядачі {#in-the-viewer}

Нижній колонтитул Parquet містить інструкції для читання під ключем `heat3d`: Z
вгору, жодна вісь не дзеркалиться, масштаб одиниці 1, тож переглядачу не потрібне
жодне зіставлення колонок. Завантажте таблицю у вкладку «Теплова карта»; див. розділи
переглядача [Завантаження даних](https://holdi601.github.io/3DHeat/getting-data-in.html)
і [Зіставлення стовпців](https://holdi601.github.io/3DHeat/column-mapping.html).
