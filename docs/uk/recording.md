# Запис демо {#recording-a-demo}

Демо Squad записуються **на сервері**, а не клієнтом гри.

1. У `Admins.cfg` сервера дайте групі адміністратора дозвіл `demos`.
2. У консолі гри виконайте `AdminDemoRec <name>`, коли починається матч.
   Адміністратор має ввести це в самій грі; один звіт каже, що RCON цього не приймає.
3. Зіграйте матч, потім виконайте `AdminDemoStop`.
4. Демо буде записано в `<server>/SquadGame/Saved/Demos/<name>.replay`.
   Скопіюйте його з сервера на комп'ютер, де його перетворюватимуть.

У `Server.cfg` також є параметр `RecordDemos`, вимкнений за замовчуванням. Для
невеликого матчу очікуйте приблизно 70–80 МБ на годину; розмір для повного сервера
на 100 гравців не вимірювався.

Демо містить імена та онлайн-ідентифікатори всіх на сервері: ставтеся до нього як до
персональних даних ([Обмеження, оновлення та умови](limits.md#personal-data)).

Далі: [Перетворення демо](converting.md).
