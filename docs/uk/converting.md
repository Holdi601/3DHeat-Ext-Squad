# Перетворення демо {#converting-demos}

```text
heat3d-squad-demo <demos or folders> -o <folder> [--flat] [--json]
python -m heat3d_ext_squad ...          те саме, але без встановлення
```

## Крок за кроком {#step-by-step}

Ви лише починаєте працювати з командним рядком? Спершу прочитайте [Перш ніж почати](before-you-start.md).

1. Встановіть один раз: `git clone https://github.com/Holdi601/3DHeat-Ext-Squad`,
   відкрийте термінал у цій папці і виконайте `python -m pip install -e .`
   (Python 3.10 або новіший; він приносить pyarrow і numpy).
2. Покладіть файли `.replay` в папку або назвіть їх по одному.
3. Виконайте `heat3d-squad-demo <folder> -o out`.
4. Ви маєте побачити один рядок на кожне демо: його шар, гравців і рядки, і куди
   записано таблицю. Кожне демо стає чотирма окремими файлами в `out/<map>/` (а
   не контейнером `.3dheat`); завантажте `.parquet` у переглядач 3DHeat.

![Запуск на синтетичному демо](../assets/img/run.svg)

На малюнку показано запуск на демо, яке будують тести (`tests/test_stream.py`),
а не на справжньому матчі.

## Параметри {#options}

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| `demos` (один або більше) | - | файли `.replay` або папки, в яких вони лежать |
| `-o`, `--out` | обов'язковий | папка, куди писати; кожне демо піде в `<out>/<map>/` |
| `--flat` | вимкнено | писати прямо в папку, без папки `<map>/` |
| `--json` | вимкнено | вивести по одному рядку JSON на кожне демо в stdout (для програм, які викликають команду): `demo`, `ok`, `parquet`, `match`, `sidecars`, `lost`, `rows`, `players`, `layer`, `recorded_unix`; демо, яке не вдалося, виводить `demo`, `ok: false` і `error` замість цього |
| `--version` | - | вивести версію і зупинитися |

Кожен параметр так, як його виводить програма: [Довідка з команд](../cli-reference.md).

Назва папки карти — це назва карти, взята зі шляху до рівня, який називає демо
(`/Game/Maps/<Map>/Gameplay_Layers/<Layer>` дає `<Map>`).

Код виходу: 0, коли кожне демо перетворено; 1, коли якесь не вдалося (інші все
одно записуються) або коли не знайдено жодного файлу `.replay`.

## Що з'являється на виході {#what-comes-out}

| Файл | Що містить |
|---|---|
| `<demo>.parquet` | таблиця: позиції і події, по одному рядку кожна ([Таблиця](output-table.md)) |
| `<demo>.match.json` | документ матчу ([Документ матчу](output-match.md)) |
| `<demo>.entities.parquet` | супутній файл: кожне оновлення властивості і кожен віддалений виклик, цілком |
| `<demo>.packets.parquet` | супутній файл: блоки файлу і все, що не було прочитано, цілком |

Таблиця і документ матчу — та сама пара, яку пише інструмент 3DHeat CS2. Переглядач
відкриває таблицю напряму і пропускає супутні файли, коли завантажує цілу папку.

## Приклади {#examples}

```bash
heat3d-squad-demo D:\SquadDemos -o out                 # кожне демо в папці
heat3d-squad-demo one.replay two.replay -o out --flat  # прямо в out/
heat3d-squad-demo D:\SquadDemos -o out --json          # один рядок JSON на кожне демо
```

`D:\SquadDemos` — це приклад папки на диску D: використовуйте свою.
