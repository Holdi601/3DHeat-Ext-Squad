# Табліца: `<demo>.parquet` {#the-table-parquet}

Адзін радок на адзнаку або падзею. Адзнака робіцца, калі сервер рэплікаваў
рух акцёра, да 8 разоў за секунду (частата запісу дэма),
пакуль ён рухаецца.

![Першыя радкі табліцы сінтэтычнага дэма](../assets/img/table.svg)

## Слупкі {#columns}

| Слупок | Што гэта |
|---|---|
| `time` | секунды ад пачатку запісу |
| `x`, `y`, `z` | пазіцыя ў адзінках Unreal (сантыметры), Z уверх |
| `dirX`, `dirY`, `dirZ` | куды глядзіць салдат: паварот цела (yaw) і нахіл погляду (pitch), як адзінкавы вектар (у тэхнікі: па гарызанталі) |
| `yaw`, `pitch` | тое ж у градусах; `pitch` уверх ад гарызонта, толькі для салдат |
| `health` | здароўе салдата, бота або тэхнікі ў гэты момант, дзе сервер яго адправіў (у салдата падае ніжэй за 0, пакуль ён паранены) |
| `speed` | рэплікаваная хуткасць, см/с |
| `player` | імя гульца; `bot <id>` для бота; для тэхнікі або размяшчальнага аб'екта без уладальніка — яго клас; для стрэлу з зброі тэхнікі — гулец, што сядзіць у гэтай тэхніцы |
| `team`, `faction` | нумар каманды Squad (1, 2) і яе налада фракцыі **у гэты момант**: гульцы могуць мяняць бок |
| `squad` | нумар аддзялення, -1, калі гулец не ў аддзяленні |
| `event` | чым з'яўляецца радок (ніжэй) |
| `pawn` | чарцёж салдата (`SQSquidBot` для бота), тэхніка або, для `fire`, зброя |
| `seat` | для вежы або пасажырскага месца — уласны pawn месца |
| `detail` | для `fire` выклік зброі, што паставіў стрэл, для `hit` тып пашкоджання, для `removed` чаму канал закрыўся (`Destroyed`, `Dormancy`...) |
| `entity` | акцёр, пра якога радок (яго сеткавы GUID): `entity` у радках дапаможных файлаў |
| `match` | назва дэма |

## Падзеі {#events}

| `event` | У радку | Што |
|---|---|---|
| `position` | салдата або бота пешшу | адзнака руху |
| `vehicle` | салдата ў наземнай тэхніцы або верталёце | адзнака ў пазіцыі тэхнікі |
| `wounded`, `revived`, `death` | салдаты і боты | дзе гэта адбылося |
| `spawn`, `damaged`, `destroyed`, `removed` | тэхніка, размяшчальныя аб'екты, агнявыя ўстаноўкі, скрыні, верталёты | дзе яны былі |
| `seat` | гулец | заняў месца |
| `fire` | страляючы | стрэл: адкуль вылецеў, яго кірунак як `yaw`/`pitch`/`dirX..Z` |
| `hit` | тэхніка | трапленне ў тэхніку: куды |

Як чытаюцца падзеі, апісана ў [Як чытаецца дэма](how-it-works.md#how-the-events-are-read).

## У праглядальніку {#in-the-viewer}

Калонтытул Parquet нясе інструкцыі для чытання пад ключом `heat3d`: Z уверх,
ніводная вось не люстраная, маштаб адзінак 1, таму праглядальніку не патрэбна супастаўленне слупкоў. Загрузіце
табліцу на ўкладцы «Цеплавая карта»; гл. у праглядальніка
[Як загрузіць даныя](https://holdi601.github.io/3DHeat/getting-data-in.html)
і [Супастаўленне слупкоў](https://holdi601.github.io/3DHeat/column-mapping.html).
