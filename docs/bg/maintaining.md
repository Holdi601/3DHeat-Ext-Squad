# Поддръжка на тези документи {#maintaining-these-docs}

Списък за всяко издание, за да не изостават страниците от кода.

1. **Регенерирайте справката.** `python tools/gen_docs_reference.py` презаписва
   [Справка за командите](../cli-reference.md) от собствения `--help` на програмата и колоните на изхода. `python tools/gen_docs_reference.py --check` излиза с код 1, когато записаната страница е остаряла.
2. **Изброете какво се е променило.** `git log v<VERSION>..HEAD --oneline`, където
   `<VERSION>` е последната издадена версия (файлът `VERSION` при издаване). Дайте на всяка нова функция, опция и колона в изхода място на страница и ред в раздела **Docs** на [`CHANGELOG.md`](https://github.com/Holdi601/3DHeat-Ext-Squad/blob/main/CHANGELOG.md).
3. **Независим преглед.** Някой, който не е писал страниците, чете README и всяка променена страница, включително картинките, три пъти: като начинаещ, който никога не е ползвал терминал, като 8-годишно дете и като експерт, който проверява всяка опция спрямо `--help`. Примерите използват измислени имена и числа само.
4. **Поправете** всичко, което прегледът намери.
5. **Преводи.** Всяка преведена страница записва хеша на английската страница, от която е направена. Превеждайте отново страниците, чийто английски източник се е променил, после прегледайте всеки език: ясен текст, верни етикети на диаграмите, същите думи, каквито използва преведеният интерфейс на визуализатора 3DHeat.
6. **Стартирайте тестовете** (`pytest`).
7. **Изпращайте** само след разрешение от собственика.

## Преводи: командите {#translations-the-commands}

Сайтът е преведен на 40-те езика на визуализатора 3DHeat: английският е в `docs/`, всеки друг език е в `docs/<lang>/` със същите имена на файлове. `tools/docs_i18n.py` води записите:

```bash
python tools/docs_i18n.py hashes             # след всяка промяна на английски текст: записва хеша на всяка страница
python tools/docs_i18n.py svg-strings        # след всяка промяна на картина: етикетите за превод
python tools/docs_i18n.py status             # за всеки език: актуални, остарели и липсващи страници
python tools/docs_i18n.py todo --lang de     # немските страници за (пре)превод
python tools/docs_i18n.py svg-build --lang de    # немските картини от docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # маркира немските страници с хеша на английския им източник
python tools/docs_i18n.py check              # излиза с код 1, когато хешовете или етикетите са остарели
```

Превеждайте само това, което `todo` показва: запазвайте Markdown, връзките, кода, имената на файловете и колоните такива, каквито са; превеждайте заглавията и описанията на картините; използвайте думите на визуализатора 3DHeat за неговите бутони и панели (`src/i18n/locales/<lang>/`). Генерираните справъчни страници и терминалните картини остават на английски. На сайта остаряла превод го казва и препраща към английската страница; липсващ превод се заменя с английския. Менюто за езици в заглавката и пренасочването на началната страница според езика на браузъра идват от `docs/_includes/`.
