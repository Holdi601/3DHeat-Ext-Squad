# Преобразуване на демота {#converting-demos}

```text
heat3d-squad-demo <demos or folders> -o <folder> [--flat] [--json]
python -m heat3d_ext_squad ...          същото, без инсталиране
```

## Стъпка по стъпка {#step-by-step}

Нов ли сте в командния ред? Първо прочетете [Преди да започнете](before-you-start.md).

1. Инсталирайте веднъж: `git clone https://github.com/Holdi601/3DHeat-Ext-Squad`,
   отворете терминал в тази папка и стартирайте `python -m pip install -e .`
   (Python 3.10 или по-нов; довежда pyarrow и numpy).
2. Сложете файловете `.replay` в една папка или ги посочете един по един.
3. Стартирайте `heat3d-squad-demo <folder> -o out`.
4. Ще видите по един ред за всяко демо: слоя му, играчите и редовете и къде е записана
   таблицата. Всяко демо става четири отделни файла в `out/<map>/` (не контейнер `.3dheat`);
   заредете `.parquet` във визуализатора 3DHeat.

![Пускане върху синтетично демо](../assets/img/run.svg)

Картинката показва пускане върху демо, което тестовете създават (`tests/test_stream.py`),
а не върху истински мач.

## Опции {#options}

| Опция | По подразбиране | Какво прави |
|---|---|---|
| `demos` (едно или повече) | - | файлове `.replay` или папки, които ги съдържат |
| `-o`, `--out` | задължителна | папката, в която се записва; всяко демо отива в `<out>/<map>/` |
| `--flat` | изключена | записва директно в папката, без папката `<map>/` |
| `--json` | изключена | извежда по един ред JSON за всяко демо на stdout (за програми, които извикват командата): `demo`, `ok`, `parquet`, `match`, `sidecars`, `lost`, `rows`, `players`, `layer`, `recorded_unix`; демо, което е неуспешно, извежда `demo`, `ok: false` и `error` вместо тях |
| `--version` | - | показва версията и спира |

Всяка опция, както я показва програмата: [Справка за командите](../cli-reference.md).

Името на папката на картата е името на картата, взето от пътя до нивото, което демото посочва
(`/Game/Maps/<Map>/Gameplay_Layers/<Layer>` дава `<Map>`).

Статус на изход: 0, когато всяко демо е преобразувано; 1, когато някое е неуспешно (другите
се записват все пак) или когато няма намерен файл `.replay`.

## Какво излиза {#what-comes-out}

| Файл | Какво съдържа |
|---|---|
| `<demo>.parquet` | таблицата: позиции и събития, по един ред всеки ([Таблицата](output-table.md)) |
| `<demo>.match.json` | документът на мача ([Документът на мача](output-match.md)) |
| `<demo>.entities.parquet` | придружаващ файл: всяка промяна на свойство и всяко отдалечено извикване, цели |
| `<demo>.packets.parquet` | придружаващ файл: частите на файла и всичко, което не е прочетено, цяло |

Таблицата и документът на мача са същата двойка, която записва инструментът 3DHeat CS2.
Визуализаторът отваря таблицата директно и пропуска придружаващите файлове, когато се зареди
цяла папка.

## Примери {#examples}

```bash
heat3d-squad-demo D:\SquadDemos -o out                 # всички демота в папка
heat3d-squad-demo one.replay two.replay -o out --flat  # направо в out/
heat3d-squad-demo D:\SquadDemos -o out --json          # по един ред JSON за демо
```

`D:\SquadDemos` е примерна папка на диск D: използвайте своя.
