# Преобразование демо {#converting-demos}

```text
heat3d-squad-demo <demos or folders> -o <folder> [--flat] [--json]
python -m heat3d_ext_squad ...          то же самое, без установки
```

## Пошагово {#step-by-step}

Впервые в командной строке? Сначала прочитайте [С чего начать](before-you-start.md).

1. Установите один раз: `git clone https://github.com/Holdi601/3DHeat-Ext-Squad`,
   откройте терминал в этой папке и выполните `python -m pip install -e .`
   (нужен Python 3.10 или новее; он подтянет pyarrow и numpy).
2. Положите файлы `.replay` в папку или перечислите их по одному.
3. Выполните `heat3d-squad-demo <folder> -o out`.
4. Вы увидите по одной строке на каждое демо: его слой, игроков и строки, а также то,
   куда записана таблица. Каждое демо становится четырьмя отдельными файлами в `out/<map>/`
   (не контейнером `.3dheat`); загрузите `.parquet` в просмотрщик 3DHeat.

![Запуск на синтетическом демо](../assets/img/run.svg)

На картинке показан запуск на демо, которое строят тесты (`tests/test_stream.py`),
а не на настоящем матче.

## Параметры {#options}

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `demos` (один или несколько) | - | файлы `.replay` или папки с ними |
| `-o`, `--out` | обязателен | папка, в которую писать; каждое демо идёт в `<out>/<map>/` |
| `--flat` | выключен | писать прямо в папку, без подпапки `<map>/` |
| `--json` | выключен | выводить на stdout по одной строке JSON на демо (для программ, которые вызывают команду): `demo`, `ok`, `parquet`, `match`, `sidecars`, `lost`, `rows`, `players`, `layer`, `recorded_unix`; демо, которое не удалось, выводит `demo`, `ok: false` и `error` |
| `--version` | - | вывести версию и остановиться |

Все параметры, как их выводит программа: [Справка по командам](../cli-reference.md).

Папка карты берётся из имени карты в пути уровня, который называет демо
(`/Game/Maps/<Map>/Gameplay_Layers/<Layer>` даёт `<Map>`).

Код выхода: 0, когда все демо преобразованы; 1, когда какое-либо не удалось (остальные
всё равно записаны), или когда не найден ни один файл `.replay`.

## Что получается {#what-comes-out}

| Файл | Что в нём |
|---|---|
| `<demo>.parquet` | таблица: позиции и события, по одной строке на каждое ([Таблица](output-table.md)) |
| `<demo>.match.json` | документ матча ([Документ матча](output-match.md)) |
| `<demo>.entities.parquet` | вспомогательный файл: каждое обновление свойств и каждый удалённый вызов целиком |
| `<demo>.packets.parquet` | вспомогательный файл: части файла и всё, что не прочиталось, целиком |

Таблица и документ матча — та же пара, что пишет инструмент 3DHeat CS2. Просмотрщик
открывает таблицу напрямую и не учитывает вспомогательные файлы, когда загружает
целую папку.

## Примеры {#examples}

```bash
heat3d-squad-demo D:\SquadDemos -o out                 # все демо в папке
heat3d-squad-demo one.replay two.replay -o out --flat  # прямо в out/
heat3d-squad-demo D:\SquadDemos -o out --json          # по одной строке JSON на демо
```

`D:\SquadDemos` — пример папки на диске D: используйте свою.
