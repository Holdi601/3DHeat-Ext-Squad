# Таблица: `<demo>.parquet` {#the-table-parquet}

Одна строка на каждый отсчёт или событие. Отсчёт берётся всякий раз, когда сервер реплицировал
движение актора, до 8 раз в секунду (частота записи демо), пока актор движется.

![Первые строки таблицы синтетического демо](../assets/img/table.svg)

## Столбцы {#columns}

| Столбец | Что это |
|---|---|
| `time` | секунды с начала записи |
| `x`, `y`, `z` | положение в единицах Unreal (сантиметрах), Z вверх |
| `dirX`, `dirY`, `dirZ` | куда смотрит солдат: поворот тела и угол взгляда по вертикали, в виде единичного вектора (у техники: горизонтально) |
| `yaw`, `pitch` | то же в градусах; `pitch` — вверх от горизонта, только у солдат |
| `health` | здоровье солдата, бота или техники в этот момент, если сервер его прислал (у раненого солдата оно падает ниже 0) |
| `speed` | реплицированная скорость, см/с |
| `player` | имя игрока; `bot <id>` для бота; для техники или развёртываемого объекта без владельца — её класс; для выстрела из оружия техники — игрок, сидящий на этой технике |
| `team`, `faction` | номер команды Squad (1, 2) и её настройка фракции, **в этот момент**: игроки могут менять стороны |
| `squad` | номер отряда, -1 если не в отряде |
| `event` | что означает строка (ниже) |
| `pawn` | блюпринт солдата (`SQSquidBot` для бота), техника, а для `fire` — оружие |
| `seat` | для сиденья турели или пассажира — собственная пешка сиденья |
| `detail` | для `fire` — вызов оружия, который поставил выстрел; для `hit` — тип урона; для `removed` — почему канал закрылся (`Destroyed`, `Dormancy`...) |
| `entity` | актор, к которому относится строка (его сетевой GUID): `entity` в строках вспомогательных файлов |
| `match` | имя демо |

## События {#events}

| `event` | В строке какого объекта | Что это |
|---|---|---|
| `position` | солдат или бот пешком | отсчёт движения |
| `vehicle` | солдат в наземной технике или на вертолёте | отсчёт по позиции техники |
| `wounded`, `revived`, `death` | солдаты и боты | где это произошло |
| `spawn`, `damaged`, `destroyed`, `removed` | техника, развёртываемые объекты, огневые точки, ящики, вертолёты | где они были |
| `seat` | игрок | занял сиденье |
| `fire` | стрелок | выстрел: откуда вылетел, направление как `yaw`/`pitch`/`dirX..Z` |
| `hit` | техника | попадание в технику: куда |

Как читаются события, описано в [Как читается демо](how-it-works.md#how-the-events-are-read).

## В просмотрщике {#in-the-viewer}

В подвале Parquet есть инструкции для чтения под ключом `heat3d`: Z вверх, ни одна ось не
отражена, масштаб 1, поэтому просмотрщику не нужно сопоставлять столбцы. Загрузите таблицу на
вкладку «Тепловая карта»; см. [Загрузка данных](https://holdi601.github.io/3DHeat/getting-data-in.html)
и [Сопоставление столбцов](https://holdi601.github.io/3DHeat/column-mapping.html) в документации просмотрщика.
