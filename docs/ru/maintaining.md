# Сопровождение документации {#maintaining-these-docs}

Контрольный список для каждого выпуска, чтобы страницы никогда не отставали от кода.

1. **Пересоздайте справку.** `python tools/gen_docs_reference.py` перезаписывает
   [Справку по командам](../cli-reference.md) по собственному `--help` программы и столбцам вывода.
   `python tools/gen_docs_reference.py --check` завершается с кодом 1, когда закоммиченная страница
   устарела.
2. **Составьте список изменений.** `git log v<VERSION>..HEAD --oneline`, где `<VERSION>` — последняя
   выпущенная версия (файл `VERSION` на момент выпуска). У каждой новой возможности, параметра и
   столбца вывода должно быть место на странице и строка в разделе **Docs** файла
   [`CHANGELOG.md`](https://github.com/Holdi601/3DHeat-Ext-Squad/blob/main/CHANGELOG.md).
3. **Независимая проверка.** Кто-то, кто не писал страницы, читает README и каждую изменённую
   страницу, включая картинки, три раза: как новичок, который никогда не пользовался терминалом,
   как восьмилетний ребёнок и как эксперт, который сверяет каждый параметр с `--help`. В примерах
   используются только выдуманные имена и числа.
4. **Исправьте** всё, что нашла проверка.
5. **Переводы.** Каждая переведённая страница хранит хеш английской страницы, с которой она сделана.
   Переведите заново страницы, чей английский источник изменился, затем проверьте каждый язык:
   понятный текст, правильные подписи на схемах, те же слова, что в переведённом интерфейсе
   визуализатора.
6. **Запустите тесты** (`pytest`).
7. **Отправьте** только после разрешения владельца.

## Переводы: команды {#translations-the-commands}

Сайт переведён на 40 языков интерфейса визуализатора 3DHeat: английский в `docs/`, каждый другой
язык в `docs/<lang>/` с теми же именами файлов. `tools/docs_i18n.py` ведёт учёт:

```bash
python tools/docs_i18n.py hashes             # после любого изменения английского текста: записать хеш каждой страницы
python tools/docs_i18n.py svg-strings        # после любого изменения картинок: подписи для перевода
python tools/docs_i18n.py status             # по каждому языку: актуально, устарело, страницы отсутствуют
python tools/docs_i18n.py todo --lang de     # немецкие страницы для (повторного) перевода
python tools/docs_i18n.py svg-build --lang de    # немецкие картинки из docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # пометить немецкие страницы хешем английского текста
python tools/docs_i18n.py check              # код 1, когда хеши или подписи устарели
```

Переводите только то, что показывает `todo`: сохраняйте Markdown, ссылки, код, имена файлов и
столбцов как есть, переводите заголовки и описания картинок, а для кнопок и панелей визуализатора
используйте его собственные слова (его `src/i18n/locales/<lang>/`). Страницы справки, созданные из
кода, и картинки терминала остаются на английском. На сайте устаревший перевод это показывает и
ведёт на английскую страницу; отсутствующий перевод открывается на английском. Меню языков в шапке
и автоматическое перенаправление главной страницы по языку браузера берутся из `docs/_includes/`.
