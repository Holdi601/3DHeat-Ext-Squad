# Запись демо {#recording-a-demo}

Демо Squad записываются **на сервере**, а не игровым клиентом.

1. В `Admins.cfg` сервера дайте группе администратора право `demos`.
2. В игровой консоли выполните `AdminDemoRec <name>` в начале матча.
   Администратор должен ввести это в самой игре; по одному отчёту, RCON это не принимает.
3. Сыграйте матч, затем выполните `AdminDemoStop`.
4. Демо будет записано в `<server>/SquadGame/Saved/Demos/<name>.replay`.
   Скопируйте его с сервера на компьютер, где будете конвертировать.

В `Server.cfg` есть также настройка `RecordDemos`, по умолчанию выключена. Ожидайте примерно
70–80 МБ в час для небольшого матча; размер для полного сервера на 100 игроков не измерен.

Демо содержит имена и онлайн-идентификаторы всех, кто был на сервере: относитесь к нему как к
личным данным ([Ограничения, обновления и условия](limits.md#личные-данные)).

Дальше: [Конвертация демо](converting.md).
