# Πριν ξεκινήσετε {#before-you-start}

Δεν έχετε ξαναδουλέψει με τη γραμμή εντολών; Αυτή η σελίδα σας πηγαίνει από το μηδέν μέχρι την πρώτη εκτέλεση.
Χρειάζεται περίπου δέκα λεπτά, μία φορά.

## 1. Εγκαταστήστε την Python {#install-python}

Αυτό το εργαλείο χρειάζεται **Python 3.10 ή νεότερη**.

- **Windows:** κατεβάστε την Python από το [python.org/downloads](https://www.python.org/downloads/)
  και τρέξτε το πρόγραμμα εγκατάστασης. Στην πρώτη οθόνη σημειώστε το **Add python.exe to PATH**,
  και μετά κάντε κλικ στο **Install Now**.
- **macOS και Linux:** η Python 3 συνήθως υπάρχει ήδη. Όπου οι σελίδες γράφουν `python`, πληκτρολογήστε `python3`.

## 2. Αποκτήστε αυτό το εργαλείο {#get-this-tool}

Ανοίξτε το [github.com/Holdi601/3DHeat-Ext-Squad](https://github.com/Holdi601/3DHeat-Ext-Squad), κάντε κλικ στο
πράσινο κουμπί **Code**, μετά στο **Download ZIP**, και αποσυμπιέστε το σε φάκελο της επιλογής σας. Αν χρησιμοποιείτε git: `git clone https://github.com/Holdi601/3DHeat-Ext-Squad`.

## 3. Ανοίξτε ένα τερματικό μέσα σε αυτόν τον φάκελο {#open-a-terminal-in-that-folder}

Το τερματικό είναι ένα παράθυρο όπου πληκτρολογείτε εντολές.

- **Windows:** ανοίξτε τον φάκελο στην Εξερεύνηση αρχείων, κάντε κλικ στη γραμμή διεύθυνσης, πληκτρολογήστε
  `powershell` και πατήστε Enter. Ανοίγει ένα μπλε ή μαύρο παράθυρο, ήδη μέσα σε αυτόν τον φάκελο.
- **macOS:** ανοίξτε το **Terminal**, πληκτρολογήστε `cd ` (με κενό), σύρετε τον φάκελο μέσα στο
  παράθυρο και πατήστε Enter.

Το `cd` σημαίνει «αλλαγή φακέλου»: το `cd C:\Tools\3DHeat-Ext-Squad` πηγαίνει σε εκείνον τον φάκελο.

## 4. Εγκαταστήστε το εργαλείο {#install-the-tool}

Πληκτρολογήστε αυτό και πατήστε Enter:

```bash
python -m pip install -e .
```

Στο τέλος πρέπει να δείτε: `Successfully installed heat3d-ext-squad-demo-...`.

## 5. Εκτελέστε το {#run-it}

```bash
heat3d-squad-demo --version
```

Θα δείτε κάτι σαν:

```text
heat3d-squad-demo 0.1.0
```

Επόμενο: [Εγγραφή ενός demo](recording.md), μετά [Μετατροπή demo](converting.md).

## Πώς να διαβάζετε τις εντολές αυτών των σελίδων {#how-to-read-the-commands-on-these-pages}

| Βλέπετε | Σημαίνει |
|---|---|
| `<folder>` | ένα σημείο κράτησης θέσης: πληκτρολογήστε αντί γι' αυτό τη δική σας τιμή, χωρίς τα `< >` |
| `[--force]` | προαιρετικό: αφήστε το έξω, ή πληκτρολογήστε το όπως φαίνεται |
| `a\|b` | επιλογή: πληκτρολογήστε `a` ή `b` |
| `# a note` | σχόλιο για εσάς: μην το πληκτρολογείτε |
| `"C:\My Files\x"` | βάλτε μια διαδρομή με κενά μέσα σε εισαγωγικά |
| `D:\Demos` | ένα παράδειγμα φακέλου των Windows: χρησιμοποιήστε τον δικό σας |

## Όταν κάτι πάει στραβά {#when-something-goes-wrong}

| Το μήνυμα | Τι να κάνετε |
|---|---|
| `'python' is not recognized` | Η Python δεν είναι εγκατεστημένη, ή δεν ήταν επιλεγμένο το PATH: εγκαταστήστε την ξανά και επιλέξτε το (ή πληκτρολογήστε `py` αντί για `python`). |
| `'heat3d-squad-demo' is not recognized` | Τρέξτε ξανά το βήμα 4 μέσα στον φάκελο του εργαλείου, ή πληκτρολογήστε `python -m heat3d_ext_squad` αντί για `heat3d-squad-demo`: κάνει το ίδιο πράγμα. |
| `No module named heat3d_ext_squad` | Δεν βρίσκεστε στον φάκελο του εργαλείου, ή απέτυχε το βήμα 4: κάντε `cd` εκεί και τρέξτε το βήμα 4. |
| `No module named pip` | Τρέξτε `python -m ensurepip`, μετά το βήμα 4. |
| οτιδήποτε άλλο | Διαβάστε την τελευταία γραμμή του μηνύματος, μετά ανοίξτε ένα ζήτημα (issue) στο GitHub με αυτή τη γραμμή. |

Κάθε εντολή τελειώνει και με έναν **κωδικό εξόδου**: το 0 σημαίνει ότι δούλεψε. Για να το δείτε,
πληκτρολογήστε `echo $LASTEXITCODE` στο PowerShell ή `echo $?` σε macOS και Linux.
