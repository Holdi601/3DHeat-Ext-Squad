# Ο πίνακας: `<demo>.parquet` {#the-table-parquet}

Μία γραμμή για κάθε δείγμα ή γεγονός. Ένα δείγμα λαμβάνεται όποτε ο server αναπαρήγαγε την κίνηση του actor, έως 8 φορές το δευτερόλεπτο (τον ρυθμό εγγραφής του demo) όσο κινείται.

![Οι πρώτες γραμμές του πίνακα ενός συνθετικού demo](../assets/img/table.svg)

## Στήλες {#columns}

| Στήλη | Τι είναι |
|---|---|
| `time` | δευτερόλεπτα από την αρχή της εγγραφής |
| `x`, `y`, `z` | θέση σε μονάδες Unreal (εκατοστά), το Z προς τα πάνω |
| `dirX`, `dirY`, `dirZ` | προς τα πού κοιτάζει ένας στρατιώτης: η γωνία στροφής του σώματος και η κλίση του βλέμματος, ως μοναδιαίο διάνυσμα (του οχήματος: οριζόντιο) |
| `yaw`, `pitch` | τα ίδια σε μοίρες· το `pitch` είναι η ανύψωση από τον ορίζοντα, μόνο για στρατιώτες |
| `health` | η υγεία του στρατιώτη, του bot ή του οχήματος εκείνη τη στιγμή, όταν τη στέλνει ο server (του στρατιώτη πέφτει κάτω από 0 όταν είναι τραυματισμένος) |
| `speed` | η αναπαραγόμενη ταχύτητα, cm/s |
| `player` | το όνομα του παίκτη· `bot <id>` για ένα bot· για ένα όχημα ή εγκαθιστώμενο αντικείμενο που δεν ανήκει σε κανέναν, η κλάση του· για πυροβολισμό από όπλο οχήματος, ο παίκτης που κάθεται σε εκείνο το όχημα |
| `team`, `faction` | ο αριθμός ομάδας του Squad (1, 2) και η ρύθμιση φατρίας του, **εκείνη τη στιγμή**: οι παίκτες μπορούν να αλλάξουν πλευρά |
| `squad` | ο αριθμός τμήματος, -1 όταν δεν ανήκει σε τμήμα |
| `event` | τι είναι η γραμμή (παρακάτω) |
| `pawn` | το blueprint του στρατιώτη (`SQSquidBot` για bot), το όχημα, ή για `fire` το όπλο |
| `seat` | για θέση πυργίσκου ή επιβάτη, το δικό pawn της θέσης |
| `detail` | για `fire` η κλήση του όπλου που όρισε τον πυροβολισμό, για `hit` ο τύπος ζημιάς, για `removed` γιατί έκλεισε το κανάλι (`Destroyed`, `Dormancy`...) |
| `entity` | η οντότητα για την οποία είναι η γραμμή (το καθολικό αναγνωριστικό δικτύου της)· το `entity` των γραμμών των βοηθητικών αρχείων |
| `match` | το όνομα του demo |

## Γεγονότα {#events}

| `event` | Στη γραμμή του | Τι είναι |
|---|---|---|
| `position` | στρατιώτη ή bot με τα πόδια | ένα δείγμα κίνησης |
| `vehicle` | στρατιώτη σε όχημα εδάφους ή ελικόπτερο | ένα δείγμα στη θέση του οχήματος |
| `wounded`, `revived`, `death` | στρατιώτες και bots | πού συνέβη |
| `spawn`, `damaged`, `destroyed`, `removed` | οχήματα, εγκαθιστώμενα αντικείμενα, θέσεις πυροβολικού, κιβώτια, ελικόπτερα | πού βρίσκονταν |
| `seat` | παίκτη | κατέλαβε μια θέση |
| `fire` | τον πυροβολητή | ένας πυροβολισμός: από πού βγήκε, η κατεύθυνσή του ως `yaw`/`pitch`/`dirX..Z` |
| `hit` | το όχημα | ένα χτύπημα οχήματος: πού |

Πώς διαβάζονται τα γεγονότα: [Πώς διαβάζεται ένα demo](how-it-works.md#how-the-events-are-read).

## Στον προβολέα {#in-the-viewer}

Το υποσέλιδο του Parquet φέρει οδηγίες ανάγνωσης κάτω από το κλειδί `heat3d`: Z προς τα πάνω,
κανένας άξονας δεν αντιστρέφεται, κλίμακα μονάδας 1, ώστε ο προβολέας να μη χρειάζεται αντιστοίχιση στηλών.
Φορτώστε τον πίνακα στην καρτέλα Χάρτης θερμότητας· δείτε το [Εισαγωγή δεδομένων](https://holdi601.github.io/3DHeat/getting-data-in.html)
και την [Αντιστοίχιση στηλών](https://holdi601.github.io/3DHeat/column-mapping.html) του προβολέα.
